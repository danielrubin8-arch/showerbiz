# showerbiz

דף נחיתה לעסק לניקוי מקלחונים וחדרי רחצה בתל אביב והמרכז. עברית בלבד, מימין לשמאל, סטטי (HTML + CSS, בלי בנייה).

## מה יש כאן

| נתיב | מה זה |
|---|---|
| `index.html` | **דף הנחיתה** (גרסה 1 שנבנתה מחדש): עולם אחד, חדר הרחצה, חמש תחנות בגלילה וכפתור צילום ששולח תמונה לוואטסאפ |
| `plan.html` | התוכנית: מבנה הדף, חמש הגרסאות בתוך טלפון, ושאלות פתוחות |
| `scrollcraft/` | הבריף של הבנייה מחדש (`builds/miklachon/BRIEF.md`) ורישום טביעות האצבע |
| `versions/` | חמש גרסאות העיצוב הראשונות (ארכיון). גרסה 1 נבחרה ב-24.11 |
| `design-system/` | `tokens.css` (צבעים, פונטים, מרווחים), `components.css` (רכיבים), `site.js` (אייקונים, וואטסאפ, סליידר), `index.html` (תצוגה) |
| `assets/img/` | תמונת הרקע (2K ו-900, webp ו-jpg), הלוגו (מקור, שקוף, מגן בלבד), favicon |
| `references/` | הרפרנסים שהעיצוב מבוסס עליהם (לא בשימוש בדף) |

## איך רואים

פותחים את `index.html` בדפדפן. או משרת מקומי מתיקיית הריפו:

```
python -m http.server 5173
```

ואז http://localhost:5173

## לפני שעולים לאוויר

- טלפון, וואטסאפ ושם העסק מוגדרים במקום אחד: `BUSINESS` בראש `design-system/site.js`.
- כל מה שמסומן בצהוב (`class="ph"`) הוא דוגמה: מחירים, דירוג, ביקורות, שעות. מחליפים באמיתי או מוחקים.
- את סרגל הטיוטה הצהוב (`draft-banner`) מוחקים.
- שכבת האבנית על הזכוכית (`assets/img/hero-limescale.webp`) מצוירת. אם יהיו תמונות לפני/אחרי אמיתיות, אפשר להחליף.
- התמונה של סתיו בתחנה "מי מגיע": `assets/img/stav-face.*` (חיתוך ריבועי מהסלפי ששלח).
